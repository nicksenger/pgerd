# pgerd

`pgerd` (/piː.ɡɜːd/ "PEE GURD") is a graphical user interface for viewing entity-relationship diagrams of PostgreSQL databases.

## Usage

`pgerd` takes a single argument with a postgres connection URL to the database you want to view, like this:

```bash
pgerd postgresql://postgres:postgres@localhost:5432/testdb
```

`pgerd` has no additional options or configuration. If you made it this far, you're an expert.
